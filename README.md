# WallPaperSync

A Windows desktop app that captures the currently rendered wallpaper—including backgrounds generated by third-party tools—and can apply that image as the lock screen.

## Description

Windows wallpaper APIs often only report a file path. Dynamic wallpaper apps may never update that path, so WallPaperSync captures the pixels actually drawn on the desktop wallpaper layer (`Progman` / `WorkerW`), hides desktop icons during capture, and displays the result in the main window. You can recapture at any time and sync the last captured image to the Windows lock screen.

## Tech Stack / Prerequisites

- Windows 10 2004+ (build 19041) or later
- .NET 10 SDK
- WPF (`net10.0-windows10.0.19041.0`)

## Installation

```bash
git clone <repository-url>
cd WallPaperSync
dotnet restore
```

## Usage

Build and run from the solution root:

```bash
dotnet run --project WallPaperSync\WallPaperSync.csproj
```

Or open `WallPaperSync.sln` in Visual Studio / JetBrains Rider and start the `WallPaperSync` project.

**Menu**

| Item | Action |
| --- | --- |
| **File → Exit** | Closes the application |
| **Capture** | Recaptures the current desktop wallpaper (wait cursor while working) |
| **Sync Lock Screen** | Saves the previously captured image and sets it as the lock screen |

The window loads with a capture of the current wallpaper. **Sync Lock Screen** uses that existing image; it does not recapture.

Saved image path:

```text
%AppData%\Jnl\Wallpaper\Wallpaper.png
```
